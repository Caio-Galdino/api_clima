Weather Data Tracker
A real-time weather tracking application that retrieves current temperature data for a specific location and provides historical temperature records for a chosen date. The system features local data persistence using a JSON file, ensuring that all recorded data is saved and remains available even after the application is restarted.

Features
Real-time Data: Fetches the current temperature for your registered locations.

Historical Records: Query historical temperature data for specific past dates.

Data Persistence: All records are saved in a JSON file, eliminating the need for re-registration after shutting down the system.
